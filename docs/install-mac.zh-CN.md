# 在 Mac 上装 cctether 插件（一步一步）

> 适合这种情况：Claude Code 跑在一台远程服务器上，服务器那边已经装好 cctether，并且配好了 HTTPS 地址（形如 `wss://你的域名/cctether`）。
> 浏览器以 Chrome 为准。Edge 等 Chromium 浏览器步骤差不多，没专门测过。

## 一、从 Chrome 应用商店安装

1. 打开 https://chromewebstore.google.com/detail/cctether/mbkadoolgknacadjkfjjajldmllbkdib ，点 **添加至 Chrome**。
2. Chrome 会弹窗列出这个插件能做什么，其中有一条「读取和更改您在所有网站上的所有数据」。听着吓人，但这是 Chrome 对调试权限（debugger）的固定提示。实际上 cctether 只动 cctether 标签组里的标签页。点 **添加扩展程序**。
3. 装好后会自动打开 cctether 的设置页，先别关。
4. 点 Chrome 右上角的拼图图标，在 cctether 旁边点图钉，把它固定到工具栏上。灰色的图标说明还没配对。

## 二、配对

1. 在服务器上，用你自己开的终端运行（在 Claude Code 里运行不会显示连接码，免得连接码进到对话里）：

   ```
   cctether pair
   ```

   它会显示一行以 `cctether1:` 开头的连接码。**整行复制**（连接码里有密钥，不要发给别人）。
2. 回到 cctether 设置页，在「和服务器配对」第 2 步的框里粘贴，点 **配对**。
3. 设置页顶部显示「已连接」，工具栏图标变成青绿色，就成功了。

## 三、如果开着代理软件

如果 Mac 上开着 Clash 之类的代理软件，给你的服务器域名加一条「直连」规则。
不然代理节点一出问题，cctether 也会跟着断。

## 四、平时怎么用

- **Claude 只能用 cctether 标签组里的标签页。** 它自己新开的标签页会自动进组。
  - 想让 Claude 看你已经打开的页面：在那个页面点工具栏上的 cctether 图标，再点 **共享**；或者直接把标签页拖进 cctether 组。
  - 拖出组，就收回来了。
- **Claude 操作页面时，Chrome 顶部会出现「“cctether”已开始调试此浏览器」的提示条。** 这是 Chrome 的规定，正常。
  - 在提示条上点「取消」，cctether 会暂停。想恢复，点工具栏图标，再点 **继续**。
- **随时可以暂停**：点工具栏图标，点 **暂停**。暂停时 Claude 碰不了任何页面。
- 弹窗里能看到最近 Claude 做了什么（点击、输入、截图……）。

## 五、出问题时看图标

| 工具栏图标 | 意思 | 怎么办 |
|---|---|---|
| 青绿色 | 已连接 | 不用管 |
| 灰色带蓝点 | 正在连接 | 等几秒 |
| 灰色带红点 | 连不上 | 点图标看原因。常见的是服务器没开、网络或代理有问题；它会自己重试 |
| 灰色带橙点 | 另一个浏览器连上了同一台服务器 | 想用这个浏览器，就点图标里的「在这里重新连接」 |
| 暂停符号 | 已暂停 | 点图标，点「继续」 |
| 纯灰色 | 还没配对 | 照第二步配对 |

弹窗里写「服务器身份不对」时，多半是服务器上换过密钥（运行过 `cctether rotate`）。在服务器上重新运行 `cctether pair`，用新的连接码再配对一次就好。

## 六、更新

- **插件**：从商店装的，Chrome 会自己更新，不用管。配对信息会保留。
- **服务器上的 cctether**：要单独更新。在服务器上运行 `npm install -g cctether@latest`，再运行 `systemctl --user restart cctether`，最后运行 `cctether check` 看一眼。

## 七、从自己加载的版本换成商店版

以前照旧步骤自己加载过插件的，换一次就好。换完以后插件会自己更新，不用再下载、替换文件夹。

1. 打开 `chrome://extensions`，在 cctether 卡片上点 **移除**。
2. 照第一步从商店安装。
3. 照第二步配对。两个版本不共用设置，所以要再贴一次连接码。连接码没变，还是 `cctether pair` 显示的那一行。
4. 看到工具栏图标变成青绿色，就换好了。「文稿」里的 `cctether-extension` 文件夹可以删掉。

两个版本不要同时装着：它们会抢同一条连接，其中一个会显示「另一个浏览器连上了」。

## 附：不用商店，自己加载

用不了应用商店，或者想用某个发布版本里的文件时：

1. 打开 https://github.com/guchaorui/cctether/releases ，在最新版本下面点 **`cctether-extension-<版本号>.zip`** 下载（不要下带 `-store` 的那个，那是给应用商店用的）。
2. 双击下载好的 zip，解压出一个 `cctether-extension` 文件夹，把它拖到「文稿」里。Chrome 每次启动都要从这个文件夹读插件，**以后别删、别挪**。
3. 在 Chrome 地址栏输入 `chrome://extensions`，回车。打开右上角的 **开发者模式** 开关。
4. 点左上角的 **加载已解压的扩展程序**，选「文稿」里的 `cctether-extension` 文件夹。同时会自动打开 cctether 的设置页。
5. 接着照第一步的第 4 条固定图标，再照第二步配对。

自己加载的版本不会自动更新。要更新时：下载新版本的 zip、解压，用里面的内容替换「文稿」里 `cctether-extension` 的内容，再到 `chrome://extensions` 点 cctether 卡片上的重新加载按钮（圆形箭头）。配对信息会保留。
